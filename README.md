# SM – Students Material | Government Startup Submission Edition

SM is a student-learning platform prototype combining study material, chapter resources, previous papers, tests, courses, a digital library, smart timetable, progress tracking, and an AI study-assistant demo in one mobile-friendly experience.

## What is included
- Working front-end prototype (HTML/CSS/JavaScript)
- Optional Express backend with health/config endpoints
- Structured JSON content model
- Smart timetable with browser persistence
- Digital library demo reader
- Tests with demo MCQs
- Government/education resource hub using official links only
- Student progress dashboard
- Kali • Kali AI demo assistant (rule-based prototype)
- Government startup proposal, technical documentation, pitch deck and submission checklist

## Run locally
1. Open `index.html` using VS Code Live Server, or
2. `cd backend && npm install && npm start`, then open `http://localhost:3000`.

## Important production note
This package is a **prototype / startup demonstration**, not a claim of government approval or official affiliation. Before public production use, replace demo content with licensed/authorized material, add secure authentication and server-side AI, implement privacy/security controls, accessibility testing, monitoring, backups, and obtain any required institutional/government permissions.

## Grades 9–12 resource hub
The study-material dataset now contains Class 9, 10, 11 and 12 chapter structures with official NCERT and DIKSHA resource links, chapter tests, practice, videos and PDFs. The app links to official resources instead of redistributing copyrighted books/videos.
